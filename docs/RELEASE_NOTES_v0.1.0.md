# Rancha 0.1.0 — first public release

An offline library and launcher for games, videos, comics and apps.

**Highlights**
- Games, Video, Reading and Applications sections with collections, tags, favorites and search.
- Launches PC games and apps; runs console games (ROMs) with RetroArch or standalone emulators.
- Comic/manga reader for CBZ, CBR, PDF and image folders.
- Big Picture fullscreen mode with keyboard/gamepad control.
- Themes, accent and icon colors, backup and restore.

**Known limits**
- Mostly tested on Windows 11; the Linux AppImage is untested on real desktops.
- Windows shows a SmartScreen warning (the app is not code-signed): More info → Run anyway.
- "Add several files at once" cannot yet classify a mixed batch of games and ROMs.
- Returning to the library automatically after a game closes is not available yet.
- Emulator command-line presets are not verified for every emulator; edit them in Settings → Emulators if one does not start.

**Downloads:** Windows installer, Windows portable, Linux AppImage (below).
