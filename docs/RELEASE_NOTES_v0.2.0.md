# Rancha 0.2.0

## New
- Online covers: search TMDB (movies/series), AniList (anime/manga), TVmaze (series) and SteamGridDB (games). Choose the database first; select a picture, then confirm it. Loading indicators while searching and downloading.
- Videos show a preview frame as their cover (a random moment between 10% and 25% of the video).
- New app icon and a custom pointing-hand cursor.
- Big Picture: full mouse control (wheel, click, right-click, back button).
- Settings reorganised into a side menu; simpler emulator list.
- Main sections (Games, Reading, Video, Applications) can no longer be deleted or moved.
- Cards: no "App / Game" label; long names use two lines. Redrawn book icon.
- Linux: programs, .desktop and .url launchers.

## Fixed
- A manga folder lost its cover after being opened for the first time.
- New libraries start empty.

## Notes
- Windows installer and Linux AppImage are unsigned: on Windows choose "More info" > "Run anyway".
- TMDB and SteamGridDB need a free key of your own (Settings > Online covers). This product uses the TMDB API but is not endorsed or certified by TMDB.
